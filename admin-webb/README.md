# Scooter Admin – React + Vite

Admin-frontend för elsparkcykelsystemet.  
Byggd i **React + Vite**, kopplad till backend via **JWT-autentisering**.

Frontend används av administratörer för att:
- logga in
- se och söka användare
- se cyklar med status, batteri och stad
- visa städer och zoner på karta (Leaflet)

---

##  Teknikstack

- React + Vite
- Axios
- React Router
- Leaflet (kartor)
- JWT-auth (via backend)
- Docker (backend)
